# Fotos personales para Pasatiempos

Puedes colocar aquí tus propias imágenes para reemplazar las fotos visuales de referencia de la sección **Pasatiempos**.

Sugerencia de nombres:

- `videojuegos.jpg`
- `viajes.jpg`
- `cocina.jpg`

Idealmente usa imágenes JPG o WebP horizontales. Cuando las subas, se pueden conectar directamente a cada tarjeta.
