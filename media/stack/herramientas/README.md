# Símbolos de herramientas

Sube aquí los símbolos o logos de tus herramientas y plataformas.

Nombres sugeridos:

- `git-github.svg` o `git-github.png`
- `google-cloud.svg` o `google-cloud.png`
- `vs-code.svg` o `vs-code.png`

Mantén los archivos con fondo transparente y formato SVG o PNG si es posible.
